# Синица — бот и мини-приложение

Telegram-бот [@sinitsa_chai_bot](https://t.me/sinitsa_chai_bot) и мини-приложение магазина китайского чая «Синица».

## Что умеет

**Покупатель (мини-приложение):**
- каталог из 29 чаёв с поиском и фильтрами, карточка чая с регионом, вкусом, эффектом и рецептами (проливами и в кружке);
- подбор чая из 5 вопросов для новичков: привычный напиток, время, любимые вкусы, что не нравится, способ заваривания → три чая («Точно понравится», «Чуть смелее», «Открытие») и пробный набор 3 × 20 г со скидкой 10%;
- корзина, фасовки 20/50/100 г и опт, оформление заказа (доставка или самовывоз);
- «Мои заказы» со статусами и отменой нового заказа.

**Бот:**
- главное меню, кнопка «Магазин» у поля ввода;
- уведомления покупателю о смене статуса;
- вопросы покупателей пересылаются продавцу, продавец отвечает через «Ответить».

**Продавец (в боте):**
- новые заказы приходят с кнопками: Принять → Отправлен → Завершён, или Отменить;
- `/active` — заказы в работе, `/stock` — включить или выключить чай в наличии, `/id` — узнать свой Telegram ID.

## Как устроено

Node.js 22, без внешних зависимостей: веб-сервер, база SQLite и Telegram API — встроенными средствами.

```
src/teas.js      каталог: названия, описания, цены, эффекты
src/catalog.js   виды чая, рецепты, признаки для подбора
src/bot.js       бот
src/server.js    API мини-приложения
src/orders.js    проверка заказа, расчёт суммы, тексты уведомлений
src/db.js        база (заказы, наличие, переписка)
public/          мини-приложение
```

Цены считает сервер по каталогу; цены из приложения не используются. Каждый запрос мини-приложения проверяется подписью Telegram.

## Цены

Розница 20/50/100 г: розница второго поставщика +15%, но не ниже закупки ×1,7. Опт: фасовка первого поставщика (как в его таблице), закупка ×1,35; если фасовка 50–100 г — от 5 фасовок. Расчёт — в таблице `sinitsa_prices.xlsx`. Чтобы поменять цену, правьте `src/teas.js`.

## Запуск на сервере (VPS)

Нужны: сервер с Docker, домен (или поддомен), направленный на IP сервера.

```bash
git clone https://github.com/gbelskiyg-gif/sinitsa-bot.git
cd sinitsa-bot
cp .env.example .env
nano .env            # BOT_TOKEN, PUBLIC_URL, ADMIN_IDS, DOMAIN
docker compose up -d --build
```

Обновление после изменений в репозитории:

```bash
git pull && docker compose up -d --build
```

База заказов лежит в папке `data/` на сервере, её стоит периодически копировать.
