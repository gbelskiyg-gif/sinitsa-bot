# Синица — бот и мини-приложение

Telegram-бот [@sinitsa_chai_bot](https://t.me/sinitsa_chai_bot) и мини-приложение магазина китайского чая «Синица».

## Что умеет

**Покупатель (мини-приложение):**
- каталог из 29 чаёв с поиском и фильтрами, карточка чая с регионом, вкусом, эффектом и рецептами (проливами и в кружке);
- подбор чая из 6 вопросов для новичков: себе или в подарок, привычный напиток, время, любимые вкусы, что не нравится, способ заваривания (в первых трёх вопросах про напиток, время и вкусы можно выбрать несколько ответов) → три чая («Точно понравится», «Чуть смелее», «Открытие») и пробный или подарочный набор 3 × 20 г со скидкой 10%. Для подарка вопросы звучат про получателя, а в подбор не попадают терпкие и спорные чаи;
- корзина, фасовки 20/50/100 г, оформление заказа с доставкой;
- опт — не через корзину: кнопка «🧑‍💼 Я оптовик» (в каталоге, в карточке чая, в приветствии бота и /opt). Продавцу в группу приходит запрос, на него можно ответить через «Ответить»; покупатель получает сообщение, что мы свяжемся лично;
- вкладка «Наборы»: готовые наборы по 3 чая («Знакомство с ГАБА», «Знакомство с пуэром», «Улуны и красный», «Утро», «Пауза», «После еды», «Знакомство») и «Собрать свой набор» из 3–6 любых чаёв; любой набор можно взять по 20, 50 или 100 г, скидка 10% (состав — `SETS` в `src/catalog.js`, размер скидки — `SET_DISCOUNT` в `public/app.js` и `src/orders.js`);
- промокод на первый заказ `SINITSA10` (−10%, не суммируется со скидкой набора; коды — `PROMOS` в `src/catalog.js`);
- «Мои заказы» со статусами, отменой нового заказа и кнопкой «Повторить».
- доставка: ПВЗ Яндекс Маркета, ПВЗ Ozon, СДЭК или Почта России (личная встреча — только для оптовиков, договариваемся в чате); ПВЗ Яндекса и Ozon — 290 ₽, СДЭК и Почта — 450 ₽ (входит в итог заказа), от 3 000 ₽ бесплатно любой службой (службы, цены и порог — `DELIVERY` и `FREE_DELIVERY_FROM` в `src/catalog.js`). В корзине — сколько осталось до бесплатной доставки, в боте — кнопка «🚚 Доставка».

**Отзывы:** через 3 дня после статуса «Завершён» бот один раз спрашивает «Как вам чай?» (👍/😐/👎) и «Чего хотелось бы в следующий раз?» (покрепче, помягче, послаще, ароматнее). Следующий подбор это учитывает: чай с оценкой «не моё» больше не предлагается, пожелание сдвигает выбор. Продавцу приходит короткая сводка. Срок можно поменять переменной `FEEDBACK_AFTER_DAYS`.

**Оплата переводом:** продавец задаёт реквизиты в боте кнопкой «💳 Реквизиты» (телефон для СБП, банк, получатель). Когда продавец принимает заказ, бот присылает покупателю сумму, реквизиты и кнопку «✅ Я оплатил» (то же — в «Моих заказах»). Продавцу приходит уведомление с кнопками «💰 Оплата получена» / «❌ Не вижу оплату». Статусы: Новый → Принят, ждёт оплаты → Оплачен → Отправлен → Завершён. Для личной встречи — оплата на месте.

**Статистика и брошенные корзины:** мини-приложение отмечает шаги (открыл магазин, вопросы подбора, открыл чай, положил в корзину, начал оформление, ошибка оформления). У продавца в боте кнопка «📊 Статистика» (/stats): путь покупателя по шагам за 7 или 30 дней, на каком вопросе бросают подбор, какие чаи смотрят чаще, список брошенных корзин с кнопкой «💬 Напомнить». Кто положил чай в корзину и за 3 часа не оформил, получает от бота одно напоминание (с 10 до 21 по Москве, не чаще раза в 14 дней; срок — `REMIND_AFTER_HOURS`). Записи о действиях хранятся 90 дней.

**Бот:**
- главное меню, кнопка «Магазин» у поля ввода;
- уведомления покупателю о смене статуса;
- вопросы покупателей пересылаются продавцу, продавец отвечает через «Ответить».

**Продавец (в боте):**
- новые заказы приходят с кнопками: Принять → Отправлен → Завершён, или Отменить;
- `/active` — заказы в работе, `/stock` — включить или выключить чай в наличии, `/id` — узнать свой Telegram ID.
- заказы, вопросы и отзывы можно направить в группу: добавить бота в группу, написать там `/chatid` и указать `ORDERS_CHAT_ID` в `.env`. Отвечать покупателю — «Ответить» на его сообщение прямо в группе (отвечать могут те, кто указан в `ADMIN_IDS`).

## Фото чаёв

Положите файл `public/teas/<номер чая>.webp` (или `.jpg`, `.png`) — фото появится в карточке и подборе. Номера чаёв — `id` в `src/teas.js`. Если своего фото нет, показывается общее фото вида чая из `public/teas/kinds/<вид>.webp` (сейчас там фирменные фото «Синицы»: ГАБА, красный, улуны, пуэры). Нет и его — иероглиф вида чая.

## Персональные данные

При оформлении заказа покупатель отмечает согласие с условиями доставки и возврата (страница `/terms`) и согласие на обработку данных (страницы `/consent` и `/privacy`). Данные продавца для этих страниц — `LEGAL` в `src/config.js` (или `OPERATOR_*` в `.env`). Через 30 дней после выполнения или отмены заказа имя, телефон, адрес и комментарий удаляются автоматически.

## Как устроено

Node.js 22, без внешних зависимостей: веб-сервер, база SQLite и Telegram API — встроенными средствами.

```
src/teas.js      каталог: названия, описания, цены, эффекты
src/catalog.js   виды чая, рецепты, признаки для подбора
src/bot.js       бот
src/server.js    API мини-приложения
src/orders.js    проверка заказа, расчёт суммы, тексты уведомлений
src/db.js        база (заказы, наличие, переписка)
public/          мини-приложение
```

Цены считает сервер по каталогу; цены из приложения не используются. Каждый запрос мини-приложения проверяется подписью Telegram.

## Цены

Розница 20/50/100 г: розница второго поставщика +15%, но не ниже закупки ×1,7. Опт (ориентир для переговоров с оптовиками, в магазине не продаётся): фасовка первого поставщика, закупка ×1,35; если фасовка 50–100 г — от 5 фасовок. Данные — поле `wholesale` в `src/teas.js`. Расчёт — в таблице `sinitsa_prices.xlsx`. Чтобы поменять цену, правьте `src/teas.js`.

## Запуск на сервере (VPS)

Нужны: сервер с Docker, домен (или поддомен), направленный на IP сервера.

```bash
git clone https://github.com/gbelskiyg-gif/sinitsa-bot.git
cd sinitsa-bot
cp .env.example .env
nano .env            # BOT_TOKEN, PUBLIC_URL, ADMIN_IDS, DOMAIN
docker compose up -d --build
```

Обновление после изменений в репозитории:

```bash
git pull && docker compose up -d --build
```

База заказов лежит в папке `data/` на сервере, её стоит периодически копировать.
